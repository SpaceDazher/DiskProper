## 7. Как сверить этот документ с реестром

Счётчик по колонке статуса, а не по слову «открыт»: подстрока «открыт» встречается и
внутри «закрыт», поэтому `grep -c 'открыт'` даёт неверное число.

**Срез реестра берётся по сводным заголовкам `### 3.1…3.4`, а не по номерам строк файла.**
Это правка прохода S3: прежний скрипт резал `docs/defects.md` по номерам строк
`[228:327]`, и после того как вверху файла добавились абзацы проходов P4, R5 и S3, срез
перестал попадать в таблицы реестра и молча считал **15 строк вместо 76**. Вывод при этом
печатался как обычно, то есть подмена инструмента выглядела как правка данных — ровно тот
класс ошибки, которому посвящён `docs/team-report.md` §5.0k.

```bash
cd /mnt/d/Project/MrProper
python3 - <<'EOF'
import re
from collections import Counter

lines = open('docs/defects.md', encoding='utf-8').read().split('\n')
def status(l):
    return [x.strip() for x in l.strip().strip('|').split('|')][-1]

sec, best = None, {}
for l in lines:
    m = re.match(r'^### (3\.\d+) ', l)
    if m:
        sec = m.group(1)
    m2 = re.match(r'^\|\s*\*{0,2}(D-\d+)\*{0,2}\s*\|', l)
    if m2 and sec and sec <= '3.4':          # первые разделы 3.1-3.4 — это сам реестр
        best.setdefault(m2.group(1), l)       # повторы в 3.10/3.11/3.16 не считаем
o = p = c = 0
open_ids = set()
for n, l in best.items():
    s = status(l)
    if s.startswith(('**закрыт', 'закрыт')):
        c += 1
    elif 'частично' in s:
        p += 1
    else:
        o += 1
        open_ids.add(n)
print(f"реестр: всего {len(best)}, открыто {o}, частично {p}, закрыто {c}")

txt = open('docs/third-party-notes.md', encoding='utf-8').read()
rows = re.findall(r'^\| (D-\d+) \| \*\*(да|нет|нужен стенд)', txt, re.M)
print("таблица разбора:", len(rows), dict(Counter(g for _, g in rows)))

sec4 = re.findall(r'^\| (D-\d+) \|', txt.split('## 4. Перепроверка')[1].split('## 5.')[0], re.M)
print("перепроверка закрытых и частичных:", len(sec4))

print("открытых строк реестра, упомянутых в разборе:", len(open_ids & {i for i, _ in rows}))
print("пропущено:", sorted(open_ids - {i for i, _ in rows}) or "нет")

sec5 = re.findall(r'^\| \*\*(\d+)\*\* \| \*\*(\d+)\*\* \|', txt.split('## 5. Трудоёмкость')[1].split('## 6.')[0], re.M)
print("трудоёмкость группы (а):", sum(int(c) for _, c in sec5), "строк по", len(sec5), "корзинам")
EOF
```
